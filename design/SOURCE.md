# Design package source

This folder is a copy of `mmPosWeb/design/` (the single source of truth,
generated by `design/scripts/build.mjs` there). Do not edit it here.

Refresh it with:

```sh
rsync -a --delete --exclude .DS_Store --exclude SOURCE.md ../mmPosWeb/design/ design/
npm run tokens   # regenerates src/shared/theme/tokens.generated.ts
```

`src/shared/theme/designParity.test.ts` fails when the generated native
tokens drift from `design/design-system/tokens.json`.
